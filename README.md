# 被执行人查询项目

这个项目用于按姓名、身份证号或企业名称查询中国执行信息公开网，并把查询结果整理为 PNG。

## 使用方式

启动 Mac 桌面 APP，推荐直接双击：

```text
启动被执行人查询助手.command
```

如果用终端启动，请使用项目自带的 Python 3.14 环境：

```bash
.venv/bin/python run_app.py
```

试用 iPhone 手机网页：

```text
启动手机网页版.command
```

启动后终端会显示两个地址。本机测试用 `127.0.0.1` 地址；iPhone 和电脑连接同一个 Wi-Fi 后，用 Safari 打开终端里显示的局域网地址。

绿联 NAS / Docker 部署：

```bash
docker compose up -d
```

详细步骤见：

[docs/绿联NAS_Docker部署说明.md](docs/绿联NAS_Docker部署说明.md)

在 APP 中可以直接粘贴批量名单。识别规则：

- 一行内有 18 位身份证号：按个人查询。
- 一行内没有身份证号：按企业查询。
- 姓名和身份证号前后顺序都可以。

个人查询输入格式：

```text
330000199001011234 张三
```

企业查询输入格式：

```text
企业：某某有限公司
```

查询流程、验证码规则、文件命名方式见：

[docs/项目使用说明.md](docs/项目使用说明.md)

## 输出目录

查询结果 PNG 保存在：

```text
results/
```

验证码图片只作为临时文件使用。查询成功后，应删除对应验证码图片。

## 隐私提醒

查询结果图片可能包含姓名、身份证号、企业名称等敏感信息。

默认不建议把 `results/*.png` 上传到公开 GitHub 仓库。如果需要备份结果图片，请优先使用私有仓库，并确认你有权保存和共享这些信息。
