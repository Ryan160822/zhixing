# 甲骨文服务器部署说明

本说明用于把手机网页版本部署到甲骨文服务器，并通过 Lucky 反代到 `zx.awuxx.de`。

## 服务信息

- 本地服务端口：`127.0.0.1:8765`
- 对外访问域名：`https://zx.awuxx.de`
- 启动文件：`run_mobile.py`
- systemd 服务名：`zxgk-mobile`

当前版本不加登录密码。公网访问后，知道域名的人都可以提交查询。

## 服务器安装

以下命令默认项目部署到：

```text
/opt/zxgk-query
```

安装基础环境：

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

创建运行用户：

```bash
sudo useradd --system --create-home --shell /usr/sbin/nologin zxgk
```

拉取项目：

```bash
sudo git clone https://github.com/Ryan160822/-.git /opt/zxgk-query
sudo chown -R zxgk:zxgk /opt/zxgk-query
```

创建 Python 环境：

```bash
cd /opt/zxgk-query
sudo -u zxgk python3 -m venv .venv
sudo -u zxgk .venv/bin/python -m pip install --upgrade pip
sudo -u zxgk .venv/bin/python -m pip install -r requirements.txt
```

安装 systemd 服务：

```bash
sudo cp /opt/zxgk-query/deploy/zxgk-mobile.service /etc/systemd/system/zxgk-mobile.service
sudo systemctl daemon-reload
sudo systemctl enable --now zxgk-mobile
```

检查服务：

```bash
systemctl status zxgk-mobile
curl -I http://127.0.0.1:8765
```

如果需要看运行日志：

```bash
journalctl -u zxgk-mobile -f
```

## Lucky 反代配置

在 Lucky 后台新增 Web 服务反向代理：

- 域名：`zx.awuxx.de`
- 后端地址：`http://127.0.0.1:8765`
- WebSocket：不需要
- HTTPS：建议开启
- 证书：使用 Lucky 自动申请或已有证书

保存后访问：

```text
https://zx.awuxx.de
```

## 更新项目

以后更新代码：

```bash
cd /opt/zxgk-query
sudo git pull

sudo -u zxgk .venv/bin/python -m pip install -r requirements.txt

```

## 常见问题

如果 Lucky 打不开：

1. 先在服务器上运行 `curl -I http://127.0.0.1:8765`。
2. 如果本机不通，检查 `systemctl status zxgk-mobile`。
3. 如果本机通但域名不通，检查 Lucky 反代目标是否是 `http://127.0.0.1:8765`。
4. 检查 `zx.awuxx.de` 的 DNS 是否指向甲骨文服务器公网 IP。
