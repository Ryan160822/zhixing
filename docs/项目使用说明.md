# 被执行人查询项目使用说明

本项目用于根据你提供的个人或企业信息，查询中国执行信息公开网结果，并把查询结果保存为 PNG 图片。

## Mac 桌面 APP

推荐启动方式：

```text
双击项目里的：启动被执行人查询助手.command
```

如果用终端启动，请在项目目录执行：

```bash
.venv/bin/python run_app.py
```

当前项目已使用 Python 3.14 环境。不要再用 macOS 自带的旧 `python3 run_app.py` 启动，否则可能出现窗口打开但内容空白的问题。

APP 支持批量粘贴，一行一个查询对象。

自动识别规则：

1. 一行内出现 18 位身份证号时，按个人查询。
2. 身份证号之外的文字按姓名处理。
3. 姓名和身份证号前后顺序都可以。
4. 一行内没有身份证号时，整行按企业名称查询。

批量查询时，APP 会按队列逐条查询。遇到验证码时自动暂停，显示放大的验证码图片，并把输入框自动聚焦。你手动输入验证码后按 `Enter` 提交，查询成功后 APP 会自动生成 PNG、删除验证码图片，并继续下一条。

## iPhone 手机网页试用版

启动方式：

```text
双击项目里的：启动手机网页版.command
```

启动后终端会显示类似下面的地址：

```text
本机打开：http://127.0.0.1:8765
iPhone 同 Wi-Fi 打开：http://192.168.x.x:8765
```

使用方法：

1. 电脑和 iPhone 连接同一个 Wi-Fi。
2. 电脑双击 `启动手机网页版.command`。
3. iPhone 用 Safari 打开终端里显示的 `http://192.168.x.x:8765` 地址。
4. 在手机页面粘贴批量名单。
5. 点击“开始查询”。
6. 页面出现验证码后，人工输入验证码并提交。
7. 查询完成后，手机页面会出现“打开 PNG”按钮。

如果 macOS 弹出网络访问或防火墙提示，需要允许 Python 接受本地网络连接，否则 iPhone 可能打不开页面。

手机试用版和 Mac 桌面版共用同一套查询规则：个人必须带身份证号，没有身份证号时按企业名称查询。企业信用信息公示系统不查询。

## 查询网站

中国执行信息公开网

- 地址：https://zxgk.court.gov.cn/zhzxgk/
- 用途：查询个人或企业是否存在被执行人信息。

## 个人查询流程

你按下面格式提供信息：

```text
身份证号 姓名
```

示例：

```text
330000199001011234 张三
```

手工处理流程：

1. 打开中国执行信息公开网综合查询页面。
2. 获取本次查询验证码图片，并保存到项目目录。
3. 我把验证码图片发给你查看。
4. 你人工读取验证码，并直接回复验证码字符。
5. 我提交姓名、身份证号和验证码进行查询。
6. 根据网站返回结果生成 PNG 图片。
7. 查询成功后删除本次验证码图片。
8. PNG 文件保存在 `results/` 目录。

输出文件命名格式：

```text
姓名_被执行人查询结果_YYYY-MM-DD.png
```

## 企业查询流程

你按下面格式提供企业名称：

```text
企业：浙江顺景建设有限公司
```

如果你明确说明“企业名字是唯一的”，则默认不再要求统一社会信用代码。

手工处理流程：

1. 先查询中国执行信息公开网。
2. 获取企业被执行人查询验证码图片。
3. 你人工读取验证码并回复。
4. 我提交企业名称和验证码。
5. 根据返回结果生成企业被执行人查询 PNG。

企业被执行人结果文件命名格式：

```text
企业名称_被执行人查询结果_YYYY-MM-DD.png
```

## 验证码规则

验证码必须由你人工读取并回复。

我不能自动识别、破解或代输验证码，即使验证码图片已经保存在项目文件夹中也不行。验证码的作用是确认真人操作，尤其查询内容涉及身份证号或企业公开信用信息。

如果验证码错误或过期：

1. 我会重新获取一张验证码图片。
2. 你重新读取并回复。
3. 我再次提交查询。

如果验证码正确并且查询成功：

1. 我会生成查询结果 PNG。
2. 我会删除本次已经用过的验证码图片。
3. 项目目录只保留查询结果 PNG 和说明文件。

## 查询结果说明

当中国执行信息公开网返回：

```text
totalSize=0
result=[]
```

表示本次查询条件下没有找到相关被执行人记录。

生成的 PNG 会包含：

1. 查询对象姓名或企业名称。
2. 身份证号或组织机构代码字段。
3. 查询法院范围。
4. 查询结果提示。
5. 查询网站地址。
6. 查询日期。

## 当前约定

1. 默认只生成 PNG，不生成 PDF。
2. 输出文件直接保存在项目目录下的 `results/` 文件夹：

```text
/Users/JAMES/Documents/被执行人及企业存续查询/results
```

3. 遇到同名企业或结果无法唯一判断时，需要你确认具体企业。
4. 身份证号属于敏感个人信息，只应查询你有权核验的信息。

## 推荐输入格式

个人：

```text
330000199001011234 张三
```

企业：

```text
企业：某某有限公司
```

如果只查被执行人：

```text
只查被执行人：某某有限公司
```
